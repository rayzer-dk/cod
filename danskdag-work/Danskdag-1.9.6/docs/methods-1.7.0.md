# Methods implemented in 1.7.0 — 25 October 2026

The request is to improve existing learning, memory and pronunciation practice without losing the full curriculum or saved progress. This release changes the current flows; it does not replace the app. A new commercial voice provider remains deferred.

## Evidence and limits

Repeated retrieval is supported by Karpicke and Roediger (2008), [original study abstract](https://pubmed.ncbi.nlm.nih.gov/18276894/). Kim and Webb (2022), [original meta-analysis](https://onlinelibrary.wiley.com/doi/abs/10.1111/lang.12479), synthesised 48 experiments with 3,411 participants and supports distributing second-language practice over time. Neither paper validates an exact universal interval schedule or this app's efficacy.

Yao et al. (2025), [original meta-analysis](https://pubmed.ncbi.nlm.nih.gov/40106429/), synthesised 65 studies with 2,793 learners and found benefits of phonetic training, with heterogeneous results and stronger perception than production effects. Uchihara, Karas and Thomson (2024), [original meta-analysis](https://www.cambridge.org/core/journals/applied-psycholinguistics/article/does-perceptual-high-variability-phonetic-training-improve-l2-speech-production-a-metaanalysis-of-perceptionproduction-connection/E38D8F5CE65DC708137B0E95F97C6BC7), found small-to-medium production effects, with limited evidence for retention/generalisation. A single system voice and manual recording loop are not equivalent to native high-variability training. This implementation is an evidence-informed teaching design, not a validated speech assessment.

FSRS-6 is an engineering memory model, documented and checked separately in adaptive-review-sources.md. Default parameters are not trained on this learner. Target retention 0.9 is a model input, not an observed guarantee. Product policy caps intervals at 90 days, uses complete elapsed 24-hour days, and leaves short error/help reviews at ten minutes. Delayed correct typed retrieval updates Good; a first unassisted error updates Again. Recognition, help, self-check and immediate retries do not create successful memory-model updates. Correct practice before the due date preserves stability, due date and context evidence. Legacy reviews migrate only on a due independent attempt; existing due dates are preserved beforehand.

Thirty existing everyday entries have two authored contexts each. Rotation and a distinct-context counter make users retrieve forms in varied situations. The counter only credits due unassisted first typed attempts on different elapsed days. It describes success in these sentence gaps, not spontaneous conversational transfer. Full dialogue lessons and original source vocabulary remain intact.

Ten pronunciation guides focus on one feature, with word contrasts, phrase chunks, whole-phrase practice and manual listening criteria. The learner can optionally record up to 20 seconds, play back, compare, delete and retry. There is no ASR, accent score, automatic correctness judgment or pronunciation XP. Audio is held only in memory and is cleared when the coach closes, navigation leaves it, the tab hides, or the page unloads. A late microphone permission response is cancelled safely. The code never uploads recordings or puts them in progress or exports.

Installed Danish voices are selectable with a Danish-only fallback. Normal/slow playback and chunk playback use that same system engine. Dictionary audio is linked as a native reference. Without a supported microphone API or permission, the learner retains listening/text/repetition practice. The independent HTML allows blob audio playback and forbids network connections. Actual microphone and Danish voice quality require supported hardware/browser and cannot be proven by lifecycle unit tests.

## Verification record

The scheduler has ten numeric and boundary tests, including literal values from pinned upstream FSRS-6. Recorder lifecycle tests cover stop, timeout, error, denial, unsupported browsers, URL cleanup and delayed permission after close. Integration tests cover state/export compatibility, selected voice, aliases, all context variants, paused sessions, model evidence gates and post-answer pronunciation access. Existing full-curriculum, progress API and cloud tests remain required.

Browser checks used the same independent bundle in a 360-pixel iframe, dark theme and 20-pixel reading size. Two due context gaps were answered; the second draft answer, session index and first result survived pause/reload. Pronunciation comparison opened the current completed context after an answer. Document scroll width matched viewport width. Desktop guide/chunk controls, missing Danish voice fallback and unsupported capture feedback were checked. Actual microphone recording/playback and native Danish speech quality were not exercised in this QA browser, which has no Danish voice and no microphone capture on its HTTP preview origin. Live two-device cloud continuity remains outside this release's verification.
