# Danskdag 1.8.0

Ukrainian is the default interface and teaching language. Russian remains selectable under «Мова навчання / Язык обучения» in Settings. The authored translation catalogue covers vocabulary glosses, contexts, grammar, instructions, answer choices, notifications and accessible labels. Danish examples and stable item/lesson identities are preserved. Explicit examples about speaking Russian and source-history quotations keep their factual meaning.

The build parses the existing JavaScript and embeds paired Russian/Ukrainian literals and template fragments into one shared application. Missing translations fail the build. The Acorn parser and its MIT notice are packaged as build tools, with no runtime dependency or remote translation service. Canonical source content and the compatibility field named `ru` remain intact.

Progress retains the same storage keys and schema. Legacy state gets Ukrainian as its missing-language default; an explicit Russian choice persists. Switching language saves before reload. Paused tasks are relocalized against the same item IDs, including parsed everyday vocabulary, exact correct choices and contextual examples. Typed answers and personal-word text remain literal. Legacy cloud base hashes are recognized before metadata upgrades to avoid a false conflict from the added setting alone. Divergent progress still requires an explicit choice.

Speaker controls show a half-second tap background/ring, followed by actual playback or error state. Opening a modal clears every background audio indication and makes the underlying app inert. A separate app stacking context keeps background focus/hover effects below the modal. Mobile shortcut icons now sit above their labels so Ukrainian navigation fits at a 20 px reading setting.

The server was serving 1.7.3 during investigation, while previously opened tabs can retain an older in-memory app or offline entry. This release checks uncached `/api/release` metadata on opening/focus/reconnect/return to the tab, and exposes a manual update check. Failed checks are distinguished from an up-to-date response. A newer version offers an explicit update through `/open`, saving progress and the unfinished session first. Updates never force a form or lesson closed. The installed offline shell now requires six files; code, CSS and illustrations are inside the coherent HTML entry. Progress and release API requests remain outside the service-worker cache.

Verification: all 211 Node tests pass, including all 2,608 built-in catalog item identities and Danish fields across both languages, and task migration in both directions in easy/expert/adaptive modes. Browser QA checked Ukrainian default, Russian/Ukrainian round-trip, literal personal-word persistence, a correct grammar response, pause at task 2/6 and Russian resume at the same position. Speaker acknowledgement/error and cleared background feedback were checked. At 360 px, dark theme and 20 px text, settings have equal scroll/client widths (345 px excluding the scrollbar); all four shortcut labels fit their button widths. The modal stays inside the viewport, with inert background and no remaining background audio indicators.

The QA browser has no Danish system voice; actual native audio quality was not assessed. Hosted two-device authenticated synchronization was not exercised live; cloud continuity uses isolated automated integration cases. The content counts, finite answer alternatives and course limitations remain unchanged.
