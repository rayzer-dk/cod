# Danskdag 1.9.7

## Сборка для обычного статического хостинга
- `npm run build:static` создаёт папку `static-site/` и архив `Danskdag-static-<версия>.zip`: загрузите её на любой HTTPS-хостинг без серверной части и баз данных (Netlify, Cloudflare Pages, GitHub Pages на корневом домене, nginx). Пошаговая инструкция внутри архива: `DEPLOY.md`.
- Отличия от Worker-версии: нет облачной синхронизации и запросов `/api/*`, прогресс хранится в браузере устройства и переносится JSON из настроек; стартовый адрес манифеста `/`; обновление через Service Worker и кнопку «Обновить»; политика безопасности задана meta-тегом с хешем скрипта, заголовки в `_headers` (Netlify и Cloudflare Pages).
- Ограничения: нужны HTTPS и корень домена (подкаталоги не поддерживаются); хостинг, который переписывает HTML, ломает проверку хешей Service Worker; GitHub Pages не читает `_headers`.
- Подробности: `static-hosting.md`.
