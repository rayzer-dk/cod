# Danskdag 1.9.1

Исправления по независимому аудиту 1.9.0. Новых разделов нет. Формат хранения прогресса (`danskdag.progress.v1`) и хеши существующих состояний сохранены.

## Упражнения
- «Собери фразу» принимает все записанные в `daAnswers` порядки слов; добавлены вторые варианты для предложений из аудита (V2: обстоятельство в начале). Если у предложения с подвижным обстоятельством нет второго порядка, задание заменяется выбором. Самопроверка доступна и для «собери фразу», но не при пустом ответе.
- Дистракторы выбираются по типу (слово против слова, тот же класс, длина, артикль); предложений среди вариантов для ответа-слова больше нет, синонимы в одном наборе исключены (проверено на всём каталоге).
- Ввод ru→da: подсказка «С артиклем: en/et» или «Глагол: at можно не писать»; единое правило для существительных и глаголов.
- Служебные слова (предлоги, союзы, частицы, местоимения) больше не проверяются одним-единственным пропуском в предложении: вместо этого перевод слова.

## Данные и надёжность
- Две вкладки: запись из устаревшей вкладки сливается с актуальным состоянием, а не затирает его (`progress-merge.mjs`); событие `storage` обновляет свободную вкладку.
- Импорт JSON и замена из облака сначала сохраняют копию (до 3 с ротацией); в настройках «Копии прогресса»: скачать или вернуть.
- Неизвестные значения настроек больше не обнуляют весь прогресс; неизвестные поля сохраняются в `_unknown`. Нечитаемые данные никогда не перезаписываются пустым состоянием; показывается баннер «Скачать копию / Начать заново».
- Service Worker: сеть для страницы с таймаутом 3 с, затем кэш (раньше мог зависать на плохой сети).
- Заголовки воркера: nosniff, Referrer-Policy, Permissions-Policy, X-Frame-Options; CSP с хешем единственного inline-скрипта для опубликованной сборки.
- Повторение: верный ответ с подсказкой не приближает срок ещё не созревшей карточки; самопроверка не удваивает `seen` и не срабатывает дважды.
- Нормализация ответов: `toLowerCase`, удаление невидимых символов; «aa» не приравнивается к «å».
- Скорость: форматтер дат вынесен из горячего пути (63,8 → 5,1 мкс), каталог слов кэшируется (рендер ≈ 45 → 3–4 мс на 2700 слов), поиск с задержкой 120 мс.

## Интерфейс и доступность
- Фокус сохраняется после ответов, перестановки плиток и поиска; при смене страницы переходит на заголовок; `document.title` меняется по разделу; обратная связь озвучивается постоянным live-region.
- Контраст светлой темы: `--muted` ≥ 4,66:1, границы полей ≥ 3:1 (`--field-line`); на сенсорных экранах цели ≥ 44 px.
- Тема следует системной, пока пользователь не выбрал свою.
- Skip-link не меняет hash; подписи навигации содержат видимый текст.
