# Requirement audit, 1.7.0

Reviewed against the complete visible chat on 25 October 2026.

Implemented: Russian-to-Danish app; modern responsive light/forest-dark interface and header theme switch; Danish flag and install icons; grammar-led A1–C1 practice and easy/mixed/expert modes; typed answers and draggable sentence tiles; wrong-answer retry within sessions and later scheduled review; retained completed lessons, XP, levels, achievements and direct/collapsed lesson navigation; custom/saved/difficult words and JSON import/export; associations, 36 subject illustrations and six picture lessons; contextual polysemy (including fyr, lede/lide and holder af), word classes, spoken-register notes and informal/coarse-language reference; quantity/comparison distinctions, 84 particle-construction examples, 114 verb paradigms, 40 adjective/quantity paradigms, 101 practical reference entries and five tense guides with lesson links; Danish audio controls for examples, forms, choices and sentence tiles; complete independent HTML launch and Windows icon/shortcut assets.

Learning methods implemented: spaced review with published FSRS-6 equations and explicit product interval bounds, retrieval practice, delayed retries, gradual introduction of new items, context, optional associations/pictures, feedback and separate evidence for recognition, assisted answers and independent recall. No claim of an optimal universal method, clinical trial of this app or guaranteed fluency is made.

Uploaded materials: both word spreadsheets have a row audit; 331 reviewed additions extend the original 838 verified file entries. Duplicates, unclear records and excluded private instructions are distinguished. All 40 uploaded comparison rows are reviewed. The PDF reference uses a checked selection of 106 PDF verbs plus eight common additions; the other 394 PDF rows were not claimed as validated. The merged dictionary has 2,633 entries, including contextual sentences and classification tasks rather than that many unique headwords. The course has 165 lessons and 897 fixed lesson exercises; reference examples can also be trained separately.

Intentionally deferred: replacement high-quality voice/native recordings, microphone pronunciation assessment and open conversation with semantic grading. The chat explicitly deferred the new voice. Written colloquial variants and existing system TTS do not reproduce all native connected-speech pronunciation.

Limitations: finite vocabulary and topic coverage; A1–C1 denotes exercise difficulty, not a complete certified CEFR course. Reading/listening/production practice here does not by itself establish conversational or professional mastery. Cloud progress code/API tests exist and hosted storage is configured, but a live account-switch/two-device end-to-end test was not completed; no such verification is claimed. Standalone HTML uses local browser storage only. Mobile file opening, PWA installation, browser cache retention and system voice availability vary. Native Windows shortcut execution and actual iPhone/Android installation were not available in this environment. The generated HTML edition was tested via the managed browser preview with a CSP disallowing external connections: navigation, embedded illustrations, a complete word exercise, saved XP after reload, local-mode settings and the 360px/20px reference table. This is not a claim of executing file:// on an actual Windows or phone OS.

Hosting: the Site is a published OpenAI Sites project independent of the active chat. The official documentation says hosting is currently included with Plus/Pro and Sites is unavailable on Free/Go; it does not state an exact shutdown or retention policy for an already published personal Site after cancellation. Do not promise perpetual hosting or a specific cancellation grace period. The downloaded HTML and full source do not depend on this subscription.

Primary hosting references: https://learn.chatgpt.com/docs/sites/managing-a-site and https://help.openai.com/en/articles/20001339-creating-and-using-chatgpt-sites .

Display-only reductions are separated from standard answer/TTS text. Daily entries avoid exact normalized overlaps with prior catalogue content. Catalogue deduplication preserves aliases for overlapping spoken sentences. No claim of complete popular vocabulary coverage is made.

Compact UI: closed reference rows, audio outside disclosures, examples/forms expanded only on request, category/query filtering and ten-row pagination, small topic training sets, vertical mobile verb forms, direct mobile section links and denser word/lesson cards. Save/difficult marking inside reference rows no longer rebuilds the page: the current disclosure, keyboard focus and scroll position stay in place. Research audit and actual form-choice/audio/navigation evidence are recorded in docs/learning-evidence-2026-10-24.md. The reported audio gaps in mixed teaching notes and V2 examples are addressed; note rendering segments Latin-script phrases and excludes speech-imitating apostrophe forms. It is not a general language-identification system.

These tasks add guided production practice; they do not measure spontaneous spoken proficiency.
