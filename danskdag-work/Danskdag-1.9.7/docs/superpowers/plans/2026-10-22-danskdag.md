# Danskdag Implementation Plan

Goal: usable first version of a Russian–Danish learning web application for phone and desktop.
Architecture: dependency-free browser modules with local versioned persistence.
Tech stack: HTML/CSS, ES modules, Node built-in tests, Web Speech synthesis, web manifest.
Spec: ../specs/2026-10-22-danskdag-design.md
Execution: native execution in the current session.

Global constraints: Russian UI; Danish study material; independent branding; local-only progress explained; no invented audio availability; no paid API; responsive accessible controls; private deployment.

Review focus: repeated completion cannot add XP twice; Danish æ/ø/å are distinct letters; malformed imports preserve existing progress; date boundaries use Europe/Copenhagen; missing browser voice/storage degrades visibly.

Task 1: engine and content. Add tests for answer normalization, explicit alternatives, SRS due dates, idempotent completion, untrusted import and Danish day boundaries. Observe missing behavior, implement engine.mjs and content.mjs, run node --test.
Task 2: UI. Create index.html, styles.css, app.mjs and icons with lesson map, player, dictionary, grammar, review, progress and settings. Use engine interfaces and verified content. Persist in-progress sessions with per-question submission guards.
Task 3: integration. Test lesson completion, mistakes and retry, reload/resume, settings, filtering and export/import. Check mobile width, keyboard operation, audio fallback, browser console. Write README with scope and limitations. Package exact pushed commit and deploy private Site.
