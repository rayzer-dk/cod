## Установка
1. **Резервная копия** БД и папки `image/`.
2. Загрузите в `/image/catalog/codecartpro/`: `images/` → `v4/` (получится `v4/banners/ru/slide-1.webp`, `v4/categories/…`, `v4/products/…`), `assets/brand/` → `brand/`, `assets/fonts/` → `fonts/`.
3. Выполните SQL по порядку `01 → 08` (09 по желанию). Префикс таблиц `oc_` — при другом замените.
4. Перед `08`: загрузите zip-архивы модулей в `system/storage/download/` под теми же именами, что в файле (по одному на модуль). Для 12 модулей архива не было — см. конец файла 08.
5. Админка → Дополнения → Модификации → «Обновить»; очистите кеш Twig/темы и изображений.
6. Проверьте `/download/`, главную, категорию, карточку модуля, мобильную версию и тёмную тему.
Откат — резервная копия БД.

## Исправление процесса покупки (v3.1) — `sql/10_fix_buy_flow.sql`
Причина двух жалоб: в настройках темы были выключены `enable_quick_order` и `enable_live_price` (окно «1 клик» вообще не выводилось в подвал, а цена не пересчитывалась). Файл 10 включает их, задаёт email заявок, обновляет CSS (окна «Кошик» и «1 клик» в стиле бренда, светлая/тёмная тема, мобильные; оформление заказа: согласие и «Продовжити»; заголовки блоков в карточке) и добавляет маленький JS для суммы в окне «Кошик». Выполните один раз, очистите кеш темы. Проверено на копии вашей страницы: цена 15→45 при количестве 3, окно открывается, ошибок JS нет.

## v3.2: что изменилось
- **Обложки** модулей (73) и категорий (18) переделаны в тёмный «премиальный» стиль: логотип, название, пункты возможностей, 3D-коробка, макет админки, плашка совместимости. Загружать в `/image/catalog/codecartpro/v4/` (новая папка — чтобы не мешал кеш).
- **Описания** всех модулей переписаны в формате с эмодзи-разделами (что за модуль, возможности, как работает, важно знать, совместимость, итог) + блоки «демо» и «где купить». Раздел «Кому подходит» убран.
- **Листинг модулей** (`/codecartpro/`): страница использовала стандартную разметку OpenCart (`.product-layout/.product-thumb`) — карточки разной высоты «зависали» в сетке, обложки обрезались. Исправлено в CSS (карточки одной высоты, квадратные обложки, кнопки бренда).
- **Тема**: два пути. Путь A (проще): выполнить `sql/10_fix_buy_flow.sql` — CSS/JS попадут в «Свой код». Путь B (чище): установить `Theme_CodeCart_Pro_v8.7.5-brand1.ocmod.zip`, затем выполнить `sql/11_theme_patch_settings.sql` (он очищает «Свой код», чтобы не дублировать). Выберите один путь.
- Порядок для обновления поверх v3.1: загрузить `images/` → `v4/`, затем выполнить `02`, `03`, `04`, `05` (обложки, баннеры, описания, категории) и `10` или `11`.
