# Danskdag 1.9.0

The home page now gives beginners one ordered route. Choose A1 and the choice-answer mode, read the introduction, then start the greeting lesson. The next topic is numbers 0–10. A1 mixes greetings, numbers, reading and grammar in an authored order; other levels retain the course order. A topic with a best score below 80% stays available for consolidation. Every topic remains manually accessible.

The selected material level A1–C1 is separate from the XP experience level. The home selector and Settings change the same saved preference without deleting results. Counts distinguish completed lessons from topics mastered at 80% or above. The expandable route displays order, checkmarks and best scores; Progress lists completed topics by level. A paused lesson can be resumed even if another level is selected. Guided sessions retain their route after reload and use it for the next-lesson result action.

An optional name in Settings personalizes the greeting and avatar. Empty names remain absent from saved settings, preserving the shape and hashes of existing nameless progress. Names are limited to 40 characters, validated and escaped at render time. Existing state, session and cloud storage keys are unchanged.

Numbers and reading are available directly from Home. The cardinal-number converter supports integers 0–9999, with Danish speech controls, a compact table and examples. Four number lessons add 24 fixed exercises; three short original A1 texts add 18 comprehension exercises. Years, phone numbers, ordinal numbers and decimal prices have other reading conventions and are explicitly outside the converter. See `basics-sources.md` for the Danish-language sources.

Known word classes display the base-language name beside the Danish term, for example noun / substantiv, verb / verbum and adjective / adjektiv. Class-recognition exercises reveal that label only after answering. Ukrainian remains the default; Russian is selectable. The course now has 165 lessons, 897 fixed exercises and 2,633 merged dictionary entries, including sentences and classification tasks rather than that many distinct words.

The first speech request waits up to two seconds for asynchronously discovered Danish voices and starts that same request when a voice arrives. Delayed discovery no longer immediately reports a missing voice. Cancellation and replacement remove pending listeners and timers. Voice-list changes update the voice selector without rerendering the page and cancelling the pending utterance. Existing tap, loading, speaking and error feedback remains in place. The provider is still browser/device speech synthesis.

Verification: 229 Node tests pass. They cover ordered progression, optional-name compatibility, guided-session restoration, class-answer concealment, number boundaries and lesson choices, translation completeness, delayed voice discovery, cancellation and existing progress/cloud behavior. Browser QA completed the first lesson at 100%, opened the second route topic, checked saved name after reload, switched levels, inspected progress, converted 123 and opened reading. Mobile QA uses a 360 px frame with 20 px text in both themes; it checks layout and controls, not physical-device speech.

The QA browser has no installed Danish voice. Native Danish audio quality and first-tap behavior on the user's actual phone still need device confirmation. No live two-device authenticated cloud-sync claim is made. The app remains practice material, not a complete CEFR certification course or an automatic assessment of spontaneous conversation.
